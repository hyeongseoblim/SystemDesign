# 학습 경험 개선 — 2026-09-08

## 사용 흐름

홈에서 제목·태그·요약을 검색하거나 미학습/학습 중/완료/복습 필요로 좁힌다. 카테고리·모드·난이도와 함께 사용할 수 있다. 기본 최신순은 기존 API의 발행일·ID 정렬이며, 랜덤 탐색을 선택하면 URL의 시드로 순서를 유지한다.

현재 규모(129개 카드)에서는 해당 카테고리·모드·난이도의 요약 전체를 기존 커서 API로 가져온 후 브라우저에서 검색한다. 첫 20개 이후에는 최대 50개씩 순차 조회한다. 본문은 상세 진입 시에만 가져온다. 전체 로딩 중이거나 일부 요청이 실패하면 결과가 부분 목록임을 표시하며 실패 지점부터 재시도한다. 표시 카드는 20개씩 늘린다. 규모가 커지면 서버 검색·집계로 전환한다.

검색어(q), 학습 상태(study), 랜덤 시드(random), 표시 개수(shown)는 URL에 유지한다. 상세의 `returnTo`는 홈 경로만 허용한다. 목록 클릭 시 현재 검색 URL별 스크롤 위치를 sessionStorage에 기록한다. 상세에서는 목차·질문·이해도 바로가기와 마지막 읽은 섹션 이동을 제공한다.

## 학습 기록

기존 `jobStudy::read::<cardId>`, `jobStudy::done::<cardId>`, `jobStudy::ans::<cardId>::<questionId>` 키를 유지한다. 새 이해도는 `jobStudy::mastery::<cardId>`에 저장한다.

- `review`: 다시 공부할래요 — 복습 목록 포함
- `hint`: 힌트가 있으면 설명 가능 — 복습 목록 포함
- `confident`: 혼자 설명 가능 — 복습 목록 제외

완료는 공부를 마쳤다는 기록이고 이해도는 자기 평가이므로 서로 독립적이다. 완료된 카드도 복습 목록에 포함될 수 있다. 자동 채점이나 복습 날짜 알고리즘은 없다. 기록은 같은 브라우저에만 저장되며 계정 동기화 기능은 없다. 저장 실패 시에는 성공 안내를 표시하지 않는다.

## 질문별 점검 기준

`apps/web/content/answer-guides.json`에 핵심 카드 10개, 질문 30개의 필수 설명 포인트·흔한 오답·꼬리 질문·출처·검수 범위를 둔다. 화면은 해당 카드의 기준만 전달받는다. `slug`와 정확한 질문 문구를 함께 확인하므로 다른 질문에 잘못 붙지 않는다. 질문을 수정하면 점검 기준도 함께 갱신한다.

범위: 시스템 디자인 기초, 용량 추정, 캐싱, 인덱스·EXPLAIN, 락·격리수준, 동시성, 트랜잭션, Outbox, 풀필먼트·재고, Hybrid Retrieval. 나머지 카드는 기존 질문 UI를 유지한다. 체크박스는 현재 화면에서 비교하는 용도이며 이해도 기록은 아래 별도 버튼으로 저장한다.

## 콘텐츠 배포

인덱스 카드의 단정 표현·조건 선택도·통계 추정·커버링 스캔 예외를 수정했다. 기존 ContentSeeder는 이미 존재하는 slug의 본문을 갱신하지 않으므로, V8 마이그레이션이 해당 MANUAL 카드 본문만 갱신한다. 카드·질문 ID와 질문 문구·발행일은 유지된다. 새 DB는 마이그레이션 이후 시더가 수정 본문을 적재한다.

API 배포 시 V8이 적용되며, 웹 배포만으로 기존 DB 본문이 바뀌지는 않는다. 유료 생성과 면접 API 설정은 변경하지 않는다.
